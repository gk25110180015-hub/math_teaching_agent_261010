根据已确认中文数学教学方案编写实际可运行的 JavaScript 动画和控件。遵循 confirmed_plan.story 及 decisions；covered_decision_ids 完整等于 decision_ids。输出 runtime_version=2。

定义 function draw(ctx,t,p)。ctx 为 960×540 离屏 Canvas 2D；t 为整段视频归一化时间 [0,1]。每帧从 t、p 独立确定性重算。只使用 Math 和 Canvas 原语，无 DOM、网络、import、eval、计时器或外部资源。运行于 Web Worker。绘图区 x=35..925,y=85..420；y<68 和 y>435 为宿主标题/字幕覆盖区。浅底，清晰线条，中文 sans-serif 字体，一般字号≥17；长公式分行；坐标必须涵盖所有参数下的点，用矩形 clip 而非 clamp 坐标伪造曲线。

运行契约（生成和修复均必须遵守）：
1. p 包含所有 controls 数值及宿主只读 p.$mode。'presentation' 是分镜演示/视频录制；'explore' 是自由探索。不要生成 mode/time/timeline/play/pause 等宿主控件。
2. presentation：按确认的累计分镜秒数实现教学顺序和动画，可按场景设定示例/方向/取点/动画步长。例如先平方函数、S3 从右侧 h=1 趋于 .02、S6 绝对值原点反例。视频不能被默认滑杆值冻结。
3. explore：所有启用的数学控件以 p 的数值为准，不能再被 t 或镜头编号覆盖。例如 h 滑杆表示当前 |h| 时，实际 h=side*p.h；示例切换控制函数、公式、切线、反例说明，最后一镜也能切回主例。动画时间仍可推进镜头。若控件在当前条件下不适用，明确禁用并给中文原因，不能显示可操作但无效果的滑杆。
4. 返回 {metrics:{...}, controls:{每个控件id:本帧实际使用的有限数值}, disabled:{不适用的控件id:'原因'}, title:'本帧中文标题', caption:'本帧中文字幕'}。disabled 无禁用时为 {}。controls 必须全部返回，值在范围内；explore 中启用控件的有效值必须等于传入值，presentation 的值可随动画变化。宿主自动同步滑杆和数值、显示禁用原因；用户调参时以当前有效参数进入 explore；重置返回 presentation。不要自行回写 DOM。
5. title 长度1–100字，caption 长度1–120字。presentation 应忠实呈现确认分镜的标题/讲解；explore 必须随实际函数、方向、求导点和结论调整，例如左侧就不能说“从右侧逼近切线”，绝对值原点就不能显示平方函数的导数结论。宿主显示你返回的标题/字幕，不会把原 story 固定字幕覆盖回来。
6. 先计算唯一的本帧有效状态，再由它派生曲线、点、割线、切线、数值表、公式、标题、字幕和 metrics；禁止绘图用动画 h 而表格用原滑杆 p.h。metrics 包含实际数学量，未定义导数等用中文字符串而非 NaN/Infinity/null。
7. 每个启用控件在当前镜头应有可观察作用。并排对照中的 side 可改变高亮的单侧；不适用则 disabled 说明。函数选择不得只改变文字或被 si===最后一镜强制覆盖。不要为通过检查虚构 controls 或 metrics；它们必须来自真正用于数学计算和绘图的状态。

数学内容依照方案。导数需真实差商、非零 h、正确导数/不可导分支；主例与反例的结论分开。局部误差由实际函数和切线计算。梯度下降需按梯度真实迭代，点位于同一目标曲面，发散则如实说明；3D 使用投影绘制曲面/轨迹并支持视角控件。至少一个参数影响数学结果。宿主提供时间轴、播放暂停和字幕，不必重复实现。
