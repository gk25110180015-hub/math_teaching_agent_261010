数学说明与适用范围

按已确认的 78 秒六镜方案实现。前五镜始终保持平方函数主线，避免示例切换造成公式和旁白矛盾；第六镜展示原点绝对值反例，example 控件改变该镜的强调状态。side 在第三镜控制从左侧或右侧缩小 h，在第四、六镜以粗线高亮所选单侧割线；x0 在平方函数镜头中改变 P、差商、切线斜率和 h² 误差。第六镜按方案锁定 x0=0。第4镜同时显示两侧差商，第5镜同时显示 |h|、h² 和误差比。

  • h 始终非零；数值演示的最小步长不是数学上的零，也不能凭有限帧证明极限存在。
  • 对平方函数，差商恒等式 m(h)=2x0+h 提供导数为 2x0 的解析依据。
  • 导数要求左右差商极限存在、相等且为有限实数；无穷斜率不视为本片定义下的导数。
  • 切线方程为 L(x)=f(x0)+f'(x0)(x-x0)，以导数存在为前提。
  • 平方函数的曲线与切线差值为 h²，说明局部线性近似并不意味着完全重合。
  • |x| 在原点连续但不可导；可导必连续，连续未必可导。
  • x0 的探索先从 1 开始，再通过滑杆观察 f'(x0)=2x0 如何随位置改变。
  • 有限帧动画只能展示数值趋近，不能替代极限存在性的严格证明；h 的最小数值为 0.02 且始终非零。
  • 第六镜的绝对值反例按确认方案固定在 x₀=0，因此该镜中 x₀ 滑杆不改变取点。
  • Canvas 使用 Unicode 数学字符排版，具体下标和撇号字形依赖运行环境的 sans-serif 字体。
