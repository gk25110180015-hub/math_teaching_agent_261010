根据已确认中文数学教学方案编写实际可运行的 JavaScript 动画和控件。遵循 confirmed_plan.story 及 decisions。完整 Program 的 covered_decision_ids 完整等于 decision_ids，runtime_version=2；局部修复 ProgramRepair 继承此契约，无需输出 code 或 runtime_version 字段。

定义 function draw(ctx,t,p)。ctx 为 960×540 离屏 Canvas 2D；t 为整段视频归一化时间 [0,1]。每帧从 t、p 独立确定性重算。只使用 Math 和 Canvas 原语，无 DOM、网络、import、eval、计时器或外部资源。运行于 Web Worker。绘图区 x=35..925,y=85..420；y<68 和 y>435 为宿主标题/字幕覆盖区。浅底，清晰线条，中文 sans-serif 字体，一般字号≥17；长公式分行；坐标必须涵盖所有参数下的点，用矩形 clip 而非 clamp 坐标伪造曲线。

运行契约（生成和修复均必须遵守）：
1. p 包含所有 controls 数值及宿主只读 p.$mode。'presentation' 是分镜演示/视频录制；'explore' 是自由探索。不要生成 mode/time/timeline/play/pause 等宿主控件。
2. presentation：按确认的累计分镜秒数实现教学顺序和动画，可按场景设定示例/方向/取点/动画步长。例如先平方函数、S3 从右侧 h=1 趋于 .02、S6 绝对值原点反例。视频不能被默认滑杆值冻结。
3. explore：所有启用的数学控件以 p 的数值为准，不能再被 t 或镜头编号覆盖。例如 h 滑杆表示当前 |h| 时，实际 h=side*p.h；示例切换控制函数、公式、切线、反例说明，最后一镜也能切回主例。动画时间仍可推进镜头。若控件在当前条件下不适用，明确禁用并给中文原因，不能显示可操作但无效果的滑杆。
4. 返回 {metrics:{...}, controls:{每个控件id:本帧实际使用的有限数值}, disabled:{不适用的控件id:'原因'}, title:'本帧中文标题', caption:'本帧中文字幕'}。disabled 无禁用时为 {}。controls 必须全部返回，值在范围内；explore 中启用控件的有效值必须等于传入值，presentation 的值可随动画变化。宿主自动同步滑杆和数值、显示禁用原因；用户调参时以当前有效参数进入 explore；重置返回 presentation。不要自行回写 DOM。
5. title 长度1–100字，caption 长度1–120字。presentation 应忠实呈现确认分镜的标题/讲解；explore 必须随实际函数、方向、求导点和结论调整，例如左侧就不能说“从右侧逼近切线”，绝对值原点就不能显示平方函数的导数结论。宿主显示你返回的标题/字幕，不会把原 story 固定字幕覆盖回来。
6. 先计算唯一的本帧有效状态，再由它派生曲线、点、割线、切线、数值表、公式、标题、字幕和 metrics；禁止绘图用动画 h 而表格用原滑杆 p.h。metrics 包含实际数学量，允许有限数值、非空中文字符串、布尔状态及其非空对象/数组；未定义导数等用中文字符串而非 NaN/Infinity/null。stationary 等状态可以是布尔值。
7. 每个启用控件在当前镜头应有可观察作用。并排对照中的 side 可改变高亮的单侧；不适用则 disabled 说明。函数选择不得只改变文字或被 si===最后一镜强制覆盖。不要为通过检查虚构 controls 或 metrics；它们必须来自真正用于数学计算和绘图的状态。
8. Canvas 几何方法的坐标和尺寸必须是有限数值。检查自定义辅助函数参数个数，例如 box(x,y,w,h,color) 不可漏掉 h；NaN 或把颜色传入高度可能被浏览器静默忽略，导致代码存在而画面缺失。运行检查会报告这类无效调用，必须修复所有调用点。

数学内容依照方案。导数需真实差商、非零 h、正确导数/不可导分支；主例与反例的结论分开。局部误差由实际函数和切线计算。梯度下降需按梯度真实迭代，点位于同一目标曲面，发散则如实说明；3D 使用投影绘制曲面/轨迹并支持视角控件。至少一个参数影响数学结果。宿主提供时间轴、播放暂停和字幕，不必重复实现。

逐镜落实：scene_requirements 按确认计划提供每镜的 visual、math、narration、start_time/end_time 和 sample_times。逐项核对 visual 中的放大、左右颜色、对照、符号区间等必须真的画在相应镜头；不能仅用说明文字、字幕、explanation 或其他镜头替代。按累计秒数切镜，不能假定每镜等长。在一个镜头展示两个关键状态时，为两者分别安排可见停留阶段，sample_times 可用于自检，不能只在采样时绘制。

导数与极值的实现约束（仅用于涉及这些内容的方案）：
- 使用数学坐标映射 X(q)、Y(y)；切线两端为 Y(f(a)+f'(a)*(q-a))，避免 Canvas 向下的 y 轴造成切线方向反转。
- 放大需改变数学视窗 xmin/xmax/ymin/ymax，并用同一映射画曲线、切点、切线、坐标刻度、左右区域。固定像素绘图区可以保留，不能把固定数学范围或扩大文字当成放大。在 metrics 返回实际视窗和当前关注点，且确实用于绘图。
- 放大镜头的过渡和 explore 也必须让当前取点及其函数值可见。可在两个驻点的停留阶段放大、过渡时恢复全图；探索时按当前点调整视窗或用全图加局部放大窗。切换到全局符号表时恢复其全局坐标映射，不能沿用局部放大范围把其他区间裁掉。驻点不属于左右开区间，单独标为“驻点/区间边界”。
- 驻点应精确取值并停留；例如 f=x³−3x 的 -1 和 1 都须展示。左右正负色带/曲线高亮要基于 f' 在两侧区间的符号，落在驻点左右的绘图区，配图例或 +/−，不能只写在侧栏。极值类型、f(a)、f'(a)、水平切线都由同一 a 派生；邻近驻点不得冒充恰在驻点。
- 检查绘制顺序与遮挡：不透明符号色带应在曲线、切线和当前点之前绘制，或放到独立区域。极小值往往接近绘图区底部，不得让后来绘制的底部色带盖住水平切线和切点。仅调用过绘制函数不能证明最终画面里可见。
- 区分“某点切线斜率为正/负”与“某区间函数递增/递减”。只展示单点导数时使用“切线斜率为正/负”或限定局部趋势；使用单调结论时显示并明确限定符号区间，同时给出该区间导数符号的解析依据。不能笼统写“当前位置处函数递增”。f'(a)=0 本身不能判定极值；可用两侧变号作充分判据，但不能宣称一般极值必须满足两侧导数变号。
