# 中性编号的三章真实 API 校准

最终校准为 **3 次真实 API 请求、6 个单元**：每章一个已知错误和一个正确对照。模型只接收中性 `U01/U02` 编号，章节之间交替错误/正确单元顺序；预期答案仅保存在本地 fixture 文件，没有发送给模型。

| 章 | 已知错误 | 检出 | 正确对照的 blocking/review 误报 |
|---|---|---|---|
| CH01 数列极限 | ε 量词从“任意”错改成“存在” | blocking | 0 |
| CH02 无穷级数 | 通项趋零被误当成级数收敛的充分条件 | blocking | 0 |
| CH03 函数极限与连续 | 极限存在却不等于点值，误称连续 | blocking | 0 |

总计 TP=3、FN=0、TN=3、FP=0。仅为基础、已知、人工编写的小样本校准，**不是随机盲测准确率、完整课程教学验收或形式化证明**；没有训练模型权重。单元、预期数学依据、完整模型审阅与实际结果分别保存在 CH01/CH02/CH03 子目录；请求和实际 usage/完整耗时保存在 state.json。费用单价未知。

先前使用 bad/good 标识的初测也通过，但标识可能提示预期结论，因此另行执行本次中性编号复测。初测全部记录保留于 ../reviewer-calibration/，不作为额外独立样本累加。两轮合计实际6次请求。此专项未执行 TeX 编译或教师人工审核。
