`reference_recovery.py` defines a bounded, strict `LabelProposal` schema and an independent `propose_reference_labels.md` role. The model returns only approved label → existing unit ID, a unique exact contiguous quotation, and a semantic rationale, or explicitly abstains. It cannot return replacement mathematics. Deterministic validation requires exact missing-label coverage, globally registered labels belonging to the section, supported numbered-unit kinds, and unique active quotation evidence. Unknown/equation anchors, invalid types, missing or duplicate bindings, invented/comment-only/non-unique quotes, and unresolved mappings block. Multiple distinct labels may share a definition.

Insertion only prepends safe `\label{...}` tokens at the beginning of the already controlled numbered environment. Every original unit ID/order/kind/association and its full original TeX suffix, calculations, calculation limitations and uncertainties remain unchanged. Semantic validity of a grounded quotation is not mechanically proved: the next local model review receives the full mapping evidence and explicit instructions to reject a mismatched or negated concept. A synthetic wrong-negation mapping is demonstrated to block at this recheck.

Recovery consumes the ordinary bounded local repair iteration; zero iterations makes no proposal call. All local normalization/content/reference/math/model checks repeat before compilation. The approved plan/hash is unchanged and no teacher review is fabricated. Valid proposals are cached by exact context, preceding sections, model, provider, prompt, schema and implementation hashes; proposal bytes are hash-checked. A later reviewer timeout reuses the unchecked mapping but repeats validation and all checks. Corrupt cache evidence blocks rather than silently regenerating it. Each attempt retains before/context/proposal/candidate/evidence files; initial raw writer candidates are untouched.
