# 三章真实 API 数学审阅校准

使用配置的 `gpt-6-astra`，通过工程真实 provider 与局部审阅接口发送 **3 次真实 API 请求**。每章各提供一个已知错误和一个正确对照；这不是随机盲测，也没有训练模型权重。

| 参考专题 | 错误基准 | 实际模型结果 | 正确对照 |
|---|---|---|---|
| CH01 数列极限 | 把任意 ε 改为存在 ε | 明确标为 blocking，并给出反例 | 无数学错误标记 |
| CH02 无穷级数 | 由通项趋零推出调和级数收敛 | 明确标为 blocking | 条件收敛论证正确；仅提示已知判别法依赖的 warning |
| CH03 函数极限与连续 | 极限存在但不等于点值，仍断言连续 | 明确标为 blocking | 连续定义通过，未误判 |

本组观察：3 个已知错误全部检出；3 个正确对照没有 blocking/review 误报。不能把这个小样本结果称为完整课程准确率，或外推为一般数学证明能力。

每个子目录保留具体输入、预期数学依据、模型完整审阅和实际结果；`state.json` 记录请求、模型、使用量、完整流式耗时与恢复状态，`summary.json` 记录混淆计数。费用单价未提供，不推算为零。数学教师审核与逐页视觉验收均未执行；本测试没有编译或生成完整讲义。
