# 实施计划（M0，2026-09-19）

已完整阅读上级目录的实施规范（1522 行）。当前没有可复用的应用工程；三个原始章节目录原地保留，第四章不纳入首批基准。新工程独立置于 `math-teaching-agent`。

1. M0：只读审计、依赖与数据清单、哈希及缺失项。
2. M1：持久化状态、不可变计划版本、真实用户决策、幂等任务和 worker，mock 双流程与本地 UI。
3. M2：兼容 chat/completions 的真实适配器、环境密钥、逐节检查、安全数学复算、讲义编译。
4. M3：保真解析、输入依赖、精确删除/新增授权、来源核查、双模板。
5. M4：语义分页、实际编译、全部页渲染、overlay 映射、人工逐页复核。
6. M5：Windows 启停、恢复、安全及真实三章矩阵，按实际证据报告；真实 API/教师审核缺少条件的格子不得写 PASS。

实施采用 Python 3.12、FastAPI/Pydantic/HTTPX、本地 SQLite 迁移和短事务队列。SQLite 原生驱动封装于持久化边界，避免 ORM 影响原子领取/栅栏语义；这是对建议 SQLAlchemy/Alembic 的明确替代，不省略版本化数据库迁移。无需 Node/WSL/Docker/Redis。

验收证据分别保存 mock、真实 API、Windows 编译、浏览器 E2E、人工视觉审核。原生编译仅 trusted_local；未实现文件系统隔离，不宣称有沙箱。
