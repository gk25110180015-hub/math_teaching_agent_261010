# 第四轮回归入口与最终语义审计步骤

## 本地回归包装器

[run_iteration4_regression.py](../../scripts/run_iteration4_regression.py) 默认只收集，完整运行须显式 `--run`。它每次动态枚举全部顶层 `tests/test_*.py`，所以之后新增的 series worker、编译恢复等测试不会漏收；嵌套 E2E 另测，真实 API 与 e2e 标记均排除。

脚本清除进程 MATH_AGENT 配置后设置两家密钥为空、live/streaming=false、provider=mock，不导入 Windows User 环境。使用新的短随机 workspace/t 目录，拒绝复用现有目录；日志/JUnit/Markdown/JSON 都写到唯一的 reports/iteration4/local-* 前缀。记录全部收集文件、逐节点结果、Windows 标记及前后 src/提示词/配置/模板/脚本/测试/锁文件 SHA。失败和产物保留；源码变化使完整执行不能以稳定快照 PASS 结束。当前 Python 进程禁止非 loopback socket.connect，不能据此声称子进程网络也受同一 audit hook 监控。

已执行语法解析和一次 **collection-only**：[收集报告](local-collect-20260920-225933-8b0578af.md)。当时 54 文件、671 项选中、1 real_api 排除、20 Windows 标记节点、157 文件 SHA 前后一致、无被拦截外连。**没有执行这些测试或编译**。之后新增测试使这些数量自然变化；最终结果以 `--run` 那次动态清单为准，不能把此次收集数量当执行通过数量。

合并冻结后从工程根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts\run_iteration4_regression.py --run
```

## 最终 CH02 / CH03 语义全覆盖审计

1. **固定最终版本再评价。** 在正常工作流到达完整 5/5 节之后，以只读 SQLite 取批准 plan/hash、每节 generated、全局报告、最终 TeX/PDF/ZIP 和请求账本；记录各 SHA。若还存在失败/预算阻塞，只评价具体可读章节，整章维持 PARTIAL，不把未生成内容算错。
2. **逐项建立证据映射。** 从 [既有语义 JSON](../iteration2/lecture_semantic_baselines.json) 提取 CH02 的 16 项 REQUIRED 和 CH03 的 22 项 REQUIRED，以及 G01–G08 跨章教学清单。每项写具体 unit_id、TeX 行、PDF 页、关键条件/证明或题解依据，取值 SATISFIED/PARTIAL/FAIL/NOT_ASSESSED；保持原 3+3 项拓展排除范围，不悄悄改变分母。
3. **完整读定义和先修链。** 检查量词、趋近过程、定义域、分母非零、单调/有界、有限极限、闭区间端点；允许使用已提供并成立的先修结论，不因未在每次应用重证而误判。先说明原稿自身几何级数下标和同阶常数口径不一致，数学正确性高于字面复制。
4. **清点本轮已知缺陷是否真的改变。** CH02 S03 U13 起点、一般几何级数范围、S04 S0/余项阈值、所有旧转义单元；CH03 S03 定义/倒数衔接、内部 ID 引用、重要极限形式和加减抵消训练；编译 U22 溢出。对每项保留修前/修后与最终版本证据，不因新 checker/prompt 部署就写“已修复”。
5. **核查每道题及答案。** 每节至少一例一练，例题解答在旁、练习答案在批准末尾位置；逐题独立复算结果、条件、索引和最小值/充分阈值语义。检查题号/标签/回链确实指向同一题；正常模型输出和 SymPy PASS 均不能免除未被工具覆盖的正文审读。
6. **评估教学方法覆盖。** CH02 要看到判别法实际应用、绝对/条件分类、误差控制和综合选择；CH03 要看到夹逼/复合的应用、合法替换及抵消辨析、连续补值、最值/介值存在性与批准经济模型。记录缺少训练、重复证明、难度跳跃与先修缺口，不以关键词、字数、页数或 proof 单元数量代替效果。
7. **单独核对工具和工作流事实。** 明确哪些表达式实际结构化计算、哪些 UNKNOWN/数值抽查；每个模型请求的实际模型与 fallback、失败/重试、每单元接受/提案次数、总请求和审批 hash。没有新的 API 请求就记录 0，不把重复校准结果当独立正确率。
8. **真实文件交付验收。** 最终全部页渲染，逐页检查公式截断、字号、表格、答案标题和链接；新目录解压源码 ZIP 实际重编译并比对 PDF 页文字/引用。Windows 成功编译、自动几何、agent 目视和教师签认分别记。没有教师实际签认时，教师数学与逐页视觉始终 NOT_RUN。

最终对照表至少包含：标准 ID、最终判断、原基准含义、实际证据、残余缺口、建议修复范围、工具覆盖边界、版本 SHA。若还需修订，按定位的实际单元走原局部/全局恢复链，不直接改已经交付的旧产物或清除失败记录。
