# 导数可视化与 Beamer 页标题修复

## 修复范围

- 可视化生成/修复使用已确认分镜的逐镜要求、累计时间范围和采样时刻，排除未选择候选方案对生成的干扰；原计划、选择和审批不变。
- 增加驻点停留、数学视窗放大、左右符号画面、探索边界、单点导数与区间单调性、驻点与开区间边界的明确约束。首轮审阅要求检查全部分镜。
- 浏览器每镜采样五次，保留每个控件在各适用镜头的证据；增加实际 Canvas 文字/颜色/矩形记录、未裁剪文字溢出检测和无效绘图参数检测。Canvas 静默忽略的错误绘图也会阻止录制。
- metrics 接受有限数值、布尔状态和非空文字；无效数据指出字段路径。检查失败继续沿用修复历史，不降低质量门槛。
- 真实回放发现完整重写会让正确的探索状态回退，已将 v2 修复改为唯一原文锚点的局部替换。所有替换相对同一个原稿执行，拒绝歧义、重叠和大范围重写，未涉及部分逐字保留。补丁原件保存在诊断目录，每版继续完整运行/数学审阅。
- Beamer 内容页和获准新增页由模型按实际分页内容拟定精简标题，目录与章节导航保留章节名；标题按页面内容与提示词缓存，分页改变会重新拟题。标题统一转义，纳入源码指纹、真实编译和版面检查。
